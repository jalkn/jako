# JAKO

JAKO is the main portfolio and central navigation layer connecting multidisciplinary visual arts research, computational systems, independent repositories, and experimental applications.

---

## 1. Important Architectural Principle

JAKO serves as the portfolio, presentation, and navigation hub. Individual projects maintain their own independent repositories, applications, experiments, assets, and documentation.

```
JAKO
↓
Portfolio / presentation / navigation
↓
Individual projects
↓
Independent repositories / applications / experiments
```

> **Architectural Note:** Do **NOT** merge all project code into the JAKO repository simply because the projects appear in the JAKO portfolio. Each initiative preserves its own independent lifecycle and codebase.

---

```
JAKO
```

## 4. Project Descriptions

### Art Projects
* **ARPA Solutions** — Full stack development, data solutions, and interface architecture (`src/data science/arpa`).
* **NZ Trip** — Aerial photography, drawing, running, performance, land art, media art, generative art (`src/art.projects/nzTrip`).
* **Drawgap** — Multidisciplinary art production / aerial photography (`src/art.projects/drawgapp`).
* **BioKinetic Drop** — Biokinetic artistic research.
* **Artepanel** — Workshop for physical and digital image-panel development (`src/art.projects/artepanel.workshop`).
* **Fotopanel.art** — Digital visualization and physical image-panel development (`src/art.projects/fotopanel.art`).
* **JAKO Ecosystem** — Overarching creative, generative, and visual arts framework (`src/art.projects/Jako Ecosystem`).
* **PULS App** — Movement-based system / artistic research (`src/art.projects/pulse app`).
* **PULSOR App** — Application related to the PULS ecosystem (`src/art.projects/pulsor app`).
* **ARDE** — Artistic research and design exploration (`src/art.projects/arde`).

### Technology & Data
* **KroxTrain** — Existing training/data project (`src/data science/kroxTrain.com`).
* **ZENERGY.LAB** — Experimental interface and computational system (`src/data science/zenergy.lab`).

### Published / Legacy Projects
* **overTsea** — Published digital interactive project.
* **jalkn.tech** — Published computational and design portfolio space.
